## สิ่งที่พบ

**1. ตัวเลขแทบไม่ขยับมา 14 ปี** เฉลี่ย 822 รายต่อปี (ราว 2.3 รายต่อวัน) เส้นแนวโน้มลาดลง 5.9 รายต่อปี
แต่ **p = 0.155** ยังไม่มีนัยสำคัญทางสถิติ จึงยังสรุปไม่ได้ว่าดีขึ้นจริงหรือเป็นความผันผวนปกติ

**2. ไม่พบการลดลงในช่วงโควิด** ปี 2563–2565 เฉลี่ย 822 ราย เทียบกับก่อนหน้าที่ 841 ราย ต่างกันไม่ถึง 3%
ทั้งที่เป็นช่วงล็อกดาวน์ ซึ่งต่างจากหลายประเทศที่ตัวเลขดิ่งลงชัดเจน — เป็นข้อสังเกตที่ยังอธิบายไม่ได้
ด้วยข้อมูลชุดนี้ ต้องมีปริมาณการจราจรมาประกอบ

**3. มอเตอร์ไซค์คือ 92.5%** ของผู้เสียชีวิตที่ระบุพาหนะได้ (ช่วงความเชื่อมั่น 95%: 91.8–93.2%, n = 5,818)
มาตรการใดที่ไม่แตะกลุ่มนี้แทบไม่มีผลต่อตัวเลขรวม

**4. กลุ่มเสี่ยงคือชายวัยทำงานตอนต้น** ชาย 82% อายุมัธยฐาน 33 ปี แต่**คนเดินเท้าที่เสียชีวิตมีอายุ
มัธยฐาน 52 ปี** ต่างจากผู้ใช้มอเตอร์ไซค์ที่ 32 ปีอย่างชัดเจน — คนละปัญหา ต้องใช้คนละมาตรการ

**5. ความเสี่ยงกระจุกตัว** ช่วงสองทุ่มถึงตีห้ากินเวลา 38% ของวันแต่มีผู้เสียชีวิต 51%
และพื้นที่เพียง 10% ของบริเวณที่เคยเกิดเหตุ รองรับผู้เสียชีวิตถึง 33% — มาตรการแบบเจาะจงจุด
น่าจะคุ้มกว่าการทำทั่วเมือง ส่วนผลของวันสุดสัปดาห์มีอยู่จริงแต่เล็ก (+8% ต่อวัน)

## ข้อจำกัดของข้อมูล

ชุดข้อมูลนี้ไม่พร้อมใช้ทันที notebook จึงใช้พื้นที่ส่วนใหญ่ไปกับการตรวจสอบและทำความสะอาดก่อนวิเคราะห์

| ปัญหาที่เจอ | ขนาด | วิธีจัดการ |
| --- | --- | --- |
| ไม่ระบุประเภทพาหนะ | 52% ของแถว | คิดสัดส่วนจากเฉพาะแถวที่ระบุได้ และระบุตัวหารกำกับทุกครั้ง |
| คอลัมน์หมวกกันน็อก/เข็มขัดนิรภัย | ว่าง 100% | ตัดทิ้ง ไม่เดาแทน |
| อายุเกิน 110 ปี (สูงสุด 149) | 31 แถว | ตัดเฉพาะค่าที่เป็นไปไม่ได้ |
| พิกัดสลับคอลัมน์ lat/lng | 479 แถว | ตรวจจับจากละติจูดเกิน 90 แล้วสลับกลับ ไม่ทิ้ง |
| พิกัดเป็น 0,0 | 2 แถว | ตัดออก ไม่งั้นจุดไปโผล่กลางมหาสมุทร |
| ปี 2568–2569 ข้อมูลยังเข้าไม่ครบ | 634 แถว | ตัดออกจากการวิเคราะห์แนวโน้มเท่านั้น |

ข้อควรระวังเพิ่มเติม: ข้อมูลนับเฉพาะ**ผู้เสียชีวิต** ไม่ใช่จำนวนอุบัติเหตุหรือผู้บาดเจ็บ,
นับตาม**จังหวัดที่เสียชีวิต**ซึ่งอาจไม่ใช่จังหวัดที่เกิดเหตุ, การกรอกประเภทพาหนะ**แย่ลงตามปี**
จึงเทียบข้ามปีไม่ได้โดยตรง, และตัวเลขทั้งหมดยังไม่ได้หารด้วยประชากรหรือปริมาณการจราจร
พื้นที่ที่แดงจึงหมายถึง "มีผู้เสียชีวิตมาก" ไม่ใช่ "อันตรายที่สุดต่อการเดินทางหนึ่งเที่ยว"
